## Лабораторная работа №1: Матрицы

## Автор

Павел Атаманов

## Описание


Шаблонный класс `MyMatrix<T>` — матрица произвольного размера

с перегрузкой операторов и поддержкой C++23 модулей.


## Возможности


- Конструкторы: с заполнением и со случайными значениями

- Операторы: `+`, `-`, `\*`, `/`, `==`, `!=`, `()`

- След матрицы

- Решение СЛАУ методом Гаусса


## Сборка

cmake -G Ninja -B build
cmake --build build


## Запуск

.\build\AiSD_Lab1.exe
